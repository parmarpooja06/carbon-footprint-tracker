\# Carbon Footprint Tracker



A Flask-based web application that helps users calculate and monitor their carbon footprint based on daily activities.



\## Features



\* User Registration

\* User Login \& Logout

\* Carbon Emission Calculator

\* Electricity Emission Tracking

\* Vehicle Emission Tracking

\* Flight Emission Tracking

\* Carbon History Tracking

\* Green Score Calculation

\* Tree Offset Recommendation

\* SQLite Database Storage



\## Technologies Used



\* Python

\* Flask

\* SQLite

\* HTML

\* CSS

\* Flask-Login

\* Flask-SQLAlchemy

\## Installation



```bash

git clone https://github.com/parmarpooja06/carbon-footprint-tracker.git



cd carbon-footprint-tracker



python -m venv venv



venv\\Scripts\\activate



python -m pip install -r requirements.txt



python app.py

```
